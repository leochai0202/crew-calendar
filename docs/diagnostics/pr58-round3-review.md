## 通用机制与最小修改

生产代码仍只改 `crew_agents/flight_prep_agent.py`，其余为回归测试与诊断。没有机场、航班、日期专用控制分支。

1. **等价表达不等于字面相同。** 在同一条完整来源中，只有 ATC、ILS、相同跑道、下滑道截获、SOP 等完整上下文及关键锚点一致，才认可 `短切五边 / short base-leg vectors` 的对应。不将孤立 base leg 与 final 一律等同。输出英文没有改成另一份翻译。
2. **准确识别原文运行表达。** `take off from / land from` 后的跑道对可识别为跑道锚点；不能把普通日期识别成跑道。真实跑道分配不等仍报错。中文 `RNP26程序` 不再因中英文字界相连而漏掉 RNP 概念。
3. **补强真实条件反转保护。** 通用装备缩写的“直到条件发生才打开”与 `remain activated ... until` 不再因数字及名词相同而通过。TCAS、GPS 的合成正反例均覆盖。正确的 only-after/inactive-until 不会被这一项误报；没有宣称该规则已证明全部时序表达。
4. **独立目的方向句按实际航段筛选。** 同一源记录中的完整独立方向句可以共同参与筛选。已知机场别名精确匹配，保留方向性与多航段 any-match；历史事件不受限制。未知地区保留原条件，不猜目的地。出现无独立条件的后续句时，不冒险拆走其父条件。英文只能从同一父记录可靠投影，否则继续 coverage gap。
5. **无编号基础块和原段落恢复。** 通用罗马数字/中文数字标题、Aerodrome/Airport elevation、Runway Information/data、Arrival Operations 等结构进入解析。保留双单位标高、完整跑道块、程序和有效限制。Location 栏目中的真实地形限制同样进入候选；只排除纯距市区距离方位资料，不按栏目名整段删除。layout 模式的原段落缩进在完整句结束后提供边界证据；跨页未完句、编号子项和条件父记录不按普通段落拆散。并保留跑道字段标签，避免丢失来源主体。
6. **轻度整理的保护测试。** 完整相关句子调整顺序可以通过；删除“必须”、将夜间换成白天或改动高度仍失败。现有 source/数字/条件/identity 校验没有关闭，也没有新增 AI 翻译或自动专业英文润色管线。
